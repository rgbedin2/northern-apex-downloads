# Northern Apex Connect

Official Northern Apex customer app downloads.

- [Download for Windows 11 — x64 EXE](https://github.com/rgbedin2/northern-apex-downloads/releases/latest/download/Northern-Apex-Connect.exe)
- [Download for macOS 15.1 or later — Intel and Apple Silicon DMG](https://github.com/rgbedin2/northern-apex-downloads/releases/latest/download/Northern-Apex-Connect.dmg)

Connect your BMW to the laptop with an OBD-to-ENET cable, keep the laptop online, and follow the app's session guide.

These are development builds. The Windows app is unsigned. The macOS app uses an ad-hoc signature and requires macOS security approval when first opened.
